# Contributing

Thanks for helping. Before a pull request can be merged we need a signed contributor agreement, which lets PlaStim
keep offering the project under its license (and to license it commercially). The agreement will be linked here
before we start accepting pull requests; issues and discussion are welcome now.

- Run the tests: `python -m pytest -q`.
- Safety first: changes to the engine's safety stack (caps, slow start, deadman, the "sensors only lower" rule) need
  a clear reason, tests, and review.
- No personal data, device serials or network details in commits.
